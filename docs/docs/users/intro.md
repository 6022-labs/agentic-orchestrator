# Introduction to Decentralized Intelligence

Decentralized Intelligence represents the convergence of two powerful paradigms in artificial intelligence:

1. Swarm AI: Inspired by natural systems like ant colonies and cellular automata, where collective intelligence emerges from simple interactions between multiple agents

2. Decentralized AI: An encompassing concept for performing distributed inference using scattered computing resources that leverage the same open-source models. Trusted Execution Environments (TEEs) facilitate this decentralization by ensuring model integrity through CPU or GPU signatures, thereby guaranteeing that all nodes are using verified, unmodified versions of the models.

Welcome to the user guide for the 6022 Agentic Teams protocol. This document provides a comprehensive and up-to-date overview (October 2025) of the architecture, features, and best practices for implementing and using decentralized AI agent teams.

The 6022 Agentic Teams protocol implements this vision by combining swarm artificial intelligence with the Ethereum blockchain to create self-organized, frugal systems that possess real digital ownership. Through this synthesis, we achieve both the emergent intelligence of swarm systems and the trustless, decentralized operation of blockchain technology.

The protocol is designed for applications enabling collaboration between humans and AI. Currently, denit is partially deployed: only the layer managing agent identity and ownership is deployed on the Ethereum blockchain. The orchestrators are centralized and managed by Swiss 6022, with future versions planned to fully decentralize agent orchestration.
