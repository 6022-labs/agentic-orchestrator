This domain curates everything that makes an agent recognizable: canonical metadata, ownership signals, and brand assets. It does not run inference; it simply keeps the public-facing profile accurate and reproducible.

What it owns:

- Core identity fields like name, role, ENS, creator, wallet list, and provenance flags that the rest of the platform reads.
- Visual assets (default/icon art, animated variants) that can be minted, pinned, or embedded anywhere the agent appears.
